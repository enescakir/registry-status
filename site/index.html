Container registry reachability

How far is ghcr.io from Europe?

ghcr.io sits behind an anycast edge, so the honest answer is measured, not assumed. Every hour, Ubicloud runners in Europe and GitHub-hosted runners in the United States push and pull the same freshly generated image and time every stage of the request. Same payload, same script, two continents.

        Method

        How these numbers are produced

        Two runners, one script

        A matrix job runs the identical probe script on a Ubicloud runner in Europe and a GitHub-hosted runner in the United States, three repetitions each, once an hour.

        A fresh payload every time

        Each repetition builds an image from random bytes. Registries deduplicate layers by digest, so re-pushing a known layer would measure nothing — a new payload forces a real transfer in both directions.

        Five timed probes

        /v2/ liveness, a token handshake, docker push, an authenticated manifest read, then docker pull with the local cache cleared.

        Results live in git

        Every measurement is appended to a JSON Lines file in the repository. There is no database and no collector to keep running — the history is the commit log.

        Known limits

        These are CI runners on shared networks, not a lab. Numbers include real scheduling noise, which is exactly what a build pipeline experiences.

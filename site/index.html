Container registry reachability

How far is ghcr.io from Europe?

ghcr.io sits behind an anycast edge, so the honest answer is measured, not assumed. Every hour, a CI runner in Europe and one in the United States push and pull the same freshly generated image and time every stage of the request. Same payload, same script, two continents.
